# 01 — Network Traffic Analysis

## Overview
This section contains practical network traffic analysis exercises conducted using Wireshark. The projects focus on understanding network protocols, examining packet communication, identifying network behaviour and investigating potential security anomalies.

## Objectives
- Understand common networking protocols.
- Analyze captured network packets.
- Identify source and destination addresses.
- Examine network communication patterns.
- Recognize unusual network behaviour.
- Develop practical network investigation skills.

## Tools
- Wireshark
- Windows
- PCAP sample datasets
- GitHub
